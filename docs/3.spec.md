## 1. 도메인 모델 및 데이터 구조 (Domain Models)

### 1.1. 식별자 분리 모델 (Identity Model)
* **`sessionId` (String/UUID)**: SSE 네트워크 소켓 커넥션 식별자.
* **`conversationId` (String/UUID)**: 비즈니스 리서치 대화 스레드 식별자.
* **`hostId` (String)**: 코틀린 스트리밍 서버 노드 식별자 (예: `kotlin-node-1`).

### 1.2. Redis 키 구조 명세 (Redis Data Structures)

#### 1. 세션 소켓 위치 저장소 (Key-Value)
* **Key**: `session:host:{sessionId}`
* **Value**: `kotlin-node-1` (소켓이 맺어져 있는 타깃 hostId)
* **TTL**: 3600초 (소켓 끊김 시 만료 제거)

#### 2. 노드별 레디스 스트림 (Redis Streams)
* **Key**: `stream:host:{hostId}` (예: `stream:host:kotlin-node-1`)
* **Value**: AgentResponseEvent JSON 페이로드

## 2. REST API 엔드포인트 명세 (API Specifications)

### 2.1. SSE 스트림 연결 (`GET /api/chat/stream`)
* **Description**: 클라이언트와 SSE 단방향 실시간 연결을 수립하고, Redis에 세션 위치(`session:host:{sessionId} -> localHostId`)를 등록합니다.
* **Headers**: `Last-Event-ID` (Optional, String): 끊김 재연결 시 마지막 수신 Redis Stream ID.
* **Query Parameters**: `conversationId` (Optional, String)
* **Response**: `text/event-stream`
* **First Event (INIT)**:
  ```json
  event: INIT
  data: {
    "type": "INIT",
    "sessionId": "sse-7dfa6d53-53bc-414e-9c67-5852e76573e7",
    "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
    "content": "SSE Connection Established"
  }
  ```

### 2.2. 리서치 질문 전송 (`POST /api/chat/message`)
* **Description**: 리서치 질문을 등록하고 백엔드 Kafka `agent-requests` 토픽으로 비동기 전달합니다.
* **Request Body**:
  ```json
  {
    "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
    "sessionId": "sse-7dfa6d53-53bc-414e-9c67-5852e76573e7",
    "query": "LiteLLM 프레임워크 조사해줘"
  }
  ```
* **Response**: `202 Accepted`

### 2.3. 이전 대화 목록 조회 (`GET /api/chat/conversations`)
* **Description**: 사용자가 과거에 수행한 리서치 대화 스레드 요약 목록을 조회합니다.

### 2.4. 특정 대화 상세 및 이전 이력 복원 조회 (`GET /api/chat/conversations/{conversationId}`)
* **Description**: 특정 대화의 전체 타임라인, 완성된 리포트 및 A2UI 대시보드 데이터를 조회합니다.
