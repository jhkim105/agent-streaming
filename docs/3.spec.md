## 1. 도메인 모델 및 데이터 구조 (Domain Models)

### 1.1. 식별자 분리 모델 (Identity Model)
* **`sessionId` (String/UUID)**: SSE 네트워크 소켓 커넥션 식별자.
* **`conversationId` (String/UUID)**: 비즈니스 리서치 대화 스레드 식별자.

### 1.2. 대화 이력 데이터 모델 (Conversation & Event Entities)

#### `Conversation` (대화 스레드 엔티티)
```kotlin
data class Conversation(
    val conversationId: String,          // 대화 유니크 식별자 (UUID)
    val title: String,                 // 대화 제목 (최초 질문 텍스트 또는 요약 제목)
    val category: String = "general",    // 질문 카테고리 (tech, business, general)
    val createdAt: Long = System.currentTimeMillis(), // 대화 생성 타임스탬프
    val updatedAt: Long = System.currentTimeMillis()  // 최근 갱신 타임스탬프
)
```

#### `ChatEvent` (개별 스트리밍 이벤트 및 리포트 엔티티)
```kotlin
data class ChatEvent(
    val id: String = UUID.randomUUID().toString(),
    val conversationId: String,          // 속한 대화 식별자
    val sessionId: String,               // 발생 당시 소켓 세션 식별자
    val hostId: String,                  // 발생 당시 서버 노드 식별자
    val type: String,                    // INIT | STATUS | CHUNK | A2UI_RENDER | DONE | ERROR
    val content: String,                 // 이벤트 텍스트 / 토큰 / JSON 페이로드
    val step: String = "",               // 추론 단계 (query_analysis, web_search, report_generation 등)
    val timestamp: Long = System.currentTimeMillis()
)
```

#### `ConversationDetailDto` (대화 상세 및 복원 DTO)
```kotlin
data class ConversationDetailDto(
    val conversationId: String,
    val title: String,
    val category: String,
    val createdAt: Long,
    val timelineEvents: List<ChatEvent>, // STATUS 이벤트 목록 (타임라인 시각화용)
    val fullReport: String,              // 축적 합성된 마크다운 최종 리포트 텍스트
    val a2uiPayload: String? = null,     // A2UI 대시보드 JSON 데이터
    val isCompleted: Boolean = false     // DONE 처리 완결 여부
)
```

## 2. REST API 엔드포인트 명세 (API Specifications)

### 2.1. SSE 스트림 연결 (`GET /api/chat/stream`)
* **Description**: 클라이언트와 SSE 단방향 실시간 연결을 수립합니다.
* **Query Parameters**:
  * `conversationId` (Optional, String): 기존 대화 스레드 이어받기 시 전달. 미전달 시 신규 `conversationId` 생성.
* **Response**: `text/event-stream`
* **First Event (INIT)**:
  ```json
  event: INIT
  data: {
    "type": "INIT",
    "sessionId": "sse-7dfa6d53-53bc-414e-9c67-5852e76573e7",
    "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
    "content": "SSE Connection Established"
  }
  ```

### 2.2. 리서치 질문 전송 (`POST /api/chat/message`)
* **Description**: 리서치 질문을 등록하고 비동기 카프카 처리로 전달합니다.
* **Request Body**:
  ```json
  {
    "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
    "sessionId": "sse-7dfa6d53-53bc-414e-9c67-5852e76573e7",
    "query": "LiteLLM 프레임워크 조사해줘"
  }
  ```
* **Response**: `202 Accepted`
  ```json
  {
    "status": "ACCEPTED",
    "message": "Research task queued successfully",
    "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
    "sessionId": "sse-7dfa6d53-53bc-414e-9c67-5852e76573e7"
  }
  ```

### 2.3. 이전 대화 목록 조회 (`GET /api/chat/conversations`)
* **Description**: 사용자가 과거에 수행한 리서치 대화 스레드 목록을 조회합니다.
* **Response**: `200 OK`
  ```json
  [
    {
      "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
      "title": "LiteLLM 프레임워크 조사해줘",
      "category": "TECH",
      "createdAt": 1786187009996,
      "updatedAt": 1786187067254
    }
  ]
  ```

### 2.4. 특정 대화 상세 및 이전 이력 복원 조회 (`GET /api/chat/conversations/{conversationId}`)
* **Description**: 특정 대화의 전체 타임라인, 완성된 리포트 및 A2UI 대시보드 데이터를 조회합니다. (새로고침 복원 및 히스토리 상세용)
* **Response**: `200 OK`
  ```json
  {
    "conversationId": "conv-a1b2c3d4-5678-90ef-ghij-1234567890ab",
    "title": "LiteLLM 프레임워크 조사해줘",
    "category": "TECH",
    "createdAt": 1786187009996,
    "timelineEvents": [
      {
        "type": "STATUS",
        "content": "🔍 사용자 질문 의도 분석 중...",
        "step": "query_analysis",
        "timestamp": 1786187009996
      }
    ],
    "fullReport": "# 📊 TECH 분야 실시간 리서치 보고서\n\n## 💡 연구 주제...",
    "a2uiPayload": "{\"version\": \"1.0\", \"title\": \"📊 TECH 대시보드\"...}",
    "isCompleted": true
  }
  ```
