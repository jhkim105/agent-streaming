# Real-time AI Researcher Agent - Implementation Plan

이 문서는 프로젝트의 단계별 구현 계획, 태스크 마일스톤 및 체크리스트를 기술합니다.

관련 문서: [요구사항 정의서](1.requirements.md) | [시스템 아키텍처](2.architecture.md) | [기술 명세서](3.spec.md)

## 1. 구현 단계별 마일스톤 (Milestones)

### Phase 1: 기반 인프라 & 기본 스트리밍 파이프라인 수립 (완료 ✅)
* [x] Kafka & Redis Docker Compose 아키텍처 환경 구축
* [x] Kotlin WebFlux SSE 기본 커넥션 및 세션 관리 (`SessionRegistry`)
* [x] Python Agent Worker (LangGraph 기본 추론 그래프) 구현
* [x] React SPA 프론트엔드 기본 채팅 스트리밍 UI 구현

### Phase 2: 멀티 노드 라우팅 & Ollama LLM 자연어 연동 (완료 ✅)
* [x] Redis Pub/Sub 기반 다중 노드 교차 세션 라우팅 (`RedisRoutingService`)
* [x] 로컬 Ollama Qwen2.5-7B LLM 연동 및 토큰 스트리밍 (`OllamaLLMClient`)
* [x] Kotest BehaviorSpec BDD 기반 통합 테스트 작성 및 통과 (`MultiNodeRoutingIntegrationTest`)
* [x] 원클릭 멀티 노드 클러스터 테스트 스크립트 구축 (`start-multi.sh`)

### Phase 3: `conversationId` 분리 & 대화 이력 보존/복원 시스템 구축 (진행 중 🚀)
* [x] `conversationId` vs `sessionId` 역할 분리 아키텍처/요구사항 명세서 반영
* [ ] Kotlin Stream Server 대화 이력 영속성 저장소 (`ConversationHistoryStore`) 개발
* [ ] 대화 이벤트 자동 축적 및 리포트 합성 릴레이 로직 구현
* [ ] REST API 개발 (`GET /api/chat/conversations`, `GET /api/chat/conversations/{conversationId}`)
* [ ] React FE 사이드바 이력 목록 UI & 새로고침 시 이력 자동 복원 연동
