## 1. 구현 단계별 로드맵 (Phases)

프로젝트는 안전하게 한 단계씩 구현 및 검증을 완료하며 진행하도록 총 5개의 단계로 나뉩니다.

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   Phase 1    │───►│   Phase 2    │───►│   Phase 3    │───►│   Phase 4    │───►│   Phase 5    │
│  인프라 구성 │    │ 파이썬에이전트│    │ 스트리밍서버 │    │ 리액트 FE UI │    │  E2E 통합 및 │
│ (Docker/Env) │    │  (LangGraph) │    │  (WebFlux)   │    │ (Vite+React) │    │ 분산 라우팅  │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

### Phase 1: 로컬 개발 환경 및 인프라 구축
* **목표**: Kafka 및 Redis 등 메시지/캐시 미들웨어를 안정적으로 띄우고, 로컬 네트워크 통신 상태를 확보합니다.
* **상세 작업**:
  * `docker-compose.yml` 작성 및 실행 테스트
  * Kafka UI 가시화 도구 설정하여 메시지 흐름 디버깅 환경 확보 (포트 `8989`)
  * Kafka 내에 `agent-requests`, `agent-responses` 토픽 생성 스크립트 마련
* **산출물**: `docker-compose.yml`, 인프라 실행 확인 스크립트

### Phase 2: Python 에이전트 & Kafka 연동 개발
* **목표**: LangGraph 기반의 멀티 스텝 에이전트 핵심 로직을 빌드하고, 연산 과정을 카프카 메시지로 전송할 수 있게 만듭니다.
* **상세 작업**:
  * **패키지 구성**: 초고속 패키지 도구인 **`uv`**를 사용하여 환경 설정 및 의존성 다운로드 (`uv venv`, `uv pip install`)
  * 웹 검색(`duckduckgo-search`) 및 웹 스크래퍼 기능 개발
  * LangGraph 추론 제어 그래프(Graph) 설계 (`agent_graph.py`)
  * 각 노드(Node)의 전환마다 카프카 `agent-responses`로 상태 및 청크 데이터 전송(Produce) 구현
* **산출물**: `agent-worker/` 소스 코드, `pyproject.toml`

### Phase 3: Kotlin Agent Stream Server 개발 (`agent-stream-server`)
* **목표**: Coroutines Flow 기반 비동기 SSE 스트림 중계 및 내부 메시지 구독 모듈을 작성합니다.
* **상세 작업**:
  * Spring Boot 3.3.2 프로젝트 초기화 및 Gradle (Kotlin DSL) 설정 (`build.gradle.kts`)
  * 로깅 표준(`kotlin-logging`) 적용 및 설정
  * Coroutine `callbackFlow` 기반 SSE 엔드포인트(`GET /api/chat/stream`) 구현 (`ChatController.kt`)
  * `POST /api/chat/message` 엔드포인트 구현 및 Kafka `agent-requests` 프로듀서 구현
  * Kafka Listener 구현하여 `agent-responses` 메시지 비동기 수신
  * 단위 테스트 구조 및 스펙 설계 (**`kotest`** 기반 테스트 코드)
* **산출물**: `agent-stream-server/` 소스 코드, Gradle 설정 파일

### Phase 4: Frontend Web Application 개발 (Vite + React)
* **목표**: 독립된 React 프론트엔드 모듈을 개발하여 SSE 통신과 타자기 효과 스트리밍 UI를 구현합니다.
* **상세 작업**:
  * Vite 기반 React + TypeScript 프로젝트 생성 및 프로젝트 구조 설계 (`frontend/`)
  * Vanilla CSS 기반 모던 디자인 시스템 토큰(Color, Typography, Card) 정의
  * SSE 수신 커넥스 훅(`useAgentStream`) 및 `sessionId` 상태 관리 개발
  * 에이전트 추론 로깅 타임라인 컴포넌트(`ChatTimeline`) 구현
  * `react-markdown`을 활용한 리포트 타자기 스트리밍 렌더러 컴포넌트(`ReportViewer`) 구현
* **산출물**: `frontend/` 디렉터리 내 React 독립 소스 코드

### Phase 5: E2E 통합, Redis 기반 분산 세션 라우팅 구현 및 최종 검증
* **목표**: 코틀린 스트리밍 서버를 여러 대 가동하고, 다른 인스턴스에 걸린 클라이언트로 메시지가 제대로 라우팅되는지 확인하며 전반적인 Latency를 프로파일링합니다.
* **상세 작업**:
  * 코틀린 스트리밍 서버 내에 Redis Reactive Template 및 Pub/Sub 연동 추가
  * 인스턴스 기동 시 유니크한 UUID Host ID 생성 및 해당 UUID를 활용한 Redis 채널 구독
  * 카프카에서 메시지를 수신했을 때 `HostID`가 불일치할 시 `Redis.publish()` 호출 및 내부 수신 중계 구현
  * 로컬 포트를 변경(8080, 8081)하여 다중 서버 모의 실행 환경 세팅
  * React 클라이언트와 연결하여 엔드투엔드 테스트 및 첫 단어 응답시간(TTFT) 프로파일링
* **산출물**: Redis 연동 코드, 다중 포트 실행 스크립트, 최종 E2E 검증 리포트

## 2. 개발 및 테스트 가이드라인 (글로벌 룰 적용)

1. **파이썬 개발 가이드**:
   * 기초 문법 요소(타입 힌트, LangGraph 노드 설계 등)에 대해 반드시 **라인 단위 한글 주석**을 명시합니다.
   * `venv` 대신 **`uv`**를 사용하여 환경 설정 속도를 최적화합니다.
2. **코틀린 개발 가이드**:
   * Spring Boot 3.x의 최신 리액티브 및 Coroutine Flow 스펙을 준수합니다.
   * 로깅 시 `Slf4j` 대신 **`kotlin-logging`** 패키지를 활용합니다.
   * 테스트 작성 시 **`kotest`**의 BDD 스타일(예: `BehaviorSpec`)을 활용하여 가독성을 높입니다.
3. **프론트엔드 개발 가이드**:
   * React 컴포넌트는 단일 책임 원칙을 준수하고, SSE 소켓 통신은 커스텀 훅(`useAgentStream`)으로 격리합니다.
   * Vanilla CSS 모던 스타일링을 적용하여 깔끔하고 세련된 UX를 구축합니다.
