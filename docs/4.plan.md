* [x] Kafka & Redis Docker Compose 아키텍처 환경 구축

* [x] React SPA 프론트엔드 대화 이력 사이드바 UI & 새로고침 복원 기능 개발

### Phase 4: ADR 0003 노드별 Redis Streams 무유실 라우팅 & 컨슈머 동적 세션 조회 (진행 예정 🚀)
